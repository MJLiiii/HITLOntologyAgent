# Known limitations and remaining gates

- The runnable application is a trusted single-machine synthetic demo. Shared identity, organization roles, confidential source handling and hosted deployment are disabled or externally gated.
- Deloitte has not selected or signed a domain scope. No consent, expert availability, independent rubric ratings, review-time observations or empirical research findings are invented.
- The scripted `demo-v1` and actual model-backed `model-pilot-v1` are distinct. Both use a single synthetic development task and cannot support a statistical effect claim. Failed model edits are retained without fallback. D gets a post-review snapshot only from a real persisted review.
- An external evaluator CLI, frozen schemas, RQ3 allocation, active-time accounting and task-level paired analysis with optional deterministic task-cluster bootstrap intervals are implemented; no empirical interval is reported without approved observations. Independent held-out study artifacts and separate OS/service identity plus agent-inaccessible mounts remain external gates; same-user private directories alone are not a security boundary. See `research/EVALUATOR.md`.
- Jena performs the admitted RDFS profile, local SHACL constraints and explicit test expectations. It is not a complete OWL 2 DL consistency proof. Unsupported constructs fail closed.
- OntoCheck uses a pinned isolated source environment and bounded local workload. Vocabulary overlap and fitness do not establish correct answers, source fidelity or equivalence. Unsupported questions, namespace collisions and unavailable scores are explicit.
- Real TrustGraph host mounting and bounded synthetic ingestion/GraphRAG/OntologyRAG source-provenance plumbing were exercised. Ordinary GraphRAG answered the known ownership question correctly; ontology-guided RAG returned a source but failed that answer check. Shared identity, approved pre-ingestion seed binding, immutable remote corpus completion, live cross-workspace denial, native-editor publication boundaries and independent held-out benchmark equivalence remain gated. See `docs/trustgraph-pipeline-smoke.md`.
- The optional TrustGraph SDK gateway is implemented and tested against controlled HTTP responses and exercised against the actual synthetic backend for exact source resolution/retrieval. Real processing completion remains unsupported, missing sources block review, and current application routing stays local until the live corpus/identity/provenance integration gates are satisfied.
- The pinned PostgreSQL 17.6 container passed isolated migration, concurrent-publication, crash-recovery and six coordinated dump/restore checks. This synthetic exercise does not replace a backup/restore rehearsal against the chosen deployment and its data. The bundled SQLite utility and separate PostgreSQL check preserve artifacts and bare Git alongside database state.
- Local code/artifact permissions are not a multi-tenant security boundary. A production deployment must isolate agent write access from approved state, publisher credentials and evaluator-held-out files.
