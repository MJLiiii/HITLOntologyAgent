# TrustGraph ingestion and evidence contract: source inspection

Read-only inspection of the pinned upstream source at `infra/portal/upstream/trustgraph-25d5d56ef6ee32a15dcd6710b9e1ab8c42419027`, on 2026-11-01. These findings describe source behavior, not a completed ingestion or runtime verification. The integration probe owns runtime evidence separately.

The librarian processing list has no terminal status. `trustgraph-base/trustgraph/schema/documents.py:155` defines `ProcessingMetadata` with only id, document_id, time, flow, collection and tags. `trustgraph-flow/trustgraph/librarian/librarian.py:180` inserts that record before invoking `load_document`; `librarian/service.py:386` sends a message to the selected text/document-load queue and returns. `tables/library.py:541–606` stores and lists these metadata rows. The only processing-record removal caller found under `trustgraph-flow/trustgraph` is the explicit librarian `remove-processing` operation. Existence therefore does not prove downstream extraction/storage completion, and disappearance is not a completion signal. The request-processing-complete logs describe local request handling.

`chunking/token/chunker.py:118–187` saves each generated chunk as a librarian child, emits provenance and sends the chunk downstream. It emits no end-of-document/count marker on this path. The chunk's random URI is also its librarian document ID. Its `parent_id` points to the input page/document; `document_type` is `chunk`. A nonempty child list or visible triples prove observed outputs only, not that every chunk and downstream stage has completed. Corpus freeze needs an externally verifiable completion/barrier contract or must remain blocked; a fixed sleep or stable count is not such a contract.

Evidence can be resolved through the following exact contracts:

| Evidence | Upstream representation/API |
| --- | --- |
| Extracted fact to extraction subgraph | Source graph `urn:graph:source`: subgraph `https://trustgraph.ai/ns/contains` RDF-star quoted triple, emitted by `extract/kg/relationships/extract.py:196` and `provenance/triples.py:318` |
| Subgraph to source chunk | Same graph: subgraph `http://www.w3.org/ns/prov#wasDerivedFrom` chunk |
| Chunk to page/document | Same graph: chunk `prov:wasDerivedFrom` parent, generated by `provenance/triples.py:229` |
| Chunk/page content and parent metadata | Workspace-scoped librarian `list-children` (`document-id`) and `get-document-content` (`document-id`, response base64 content); `api/library.py:955,1009` |
| Graph query | `api/flow.py:795` `triples_query(s,p,o,g,collection,limit)`; explicit collection and `g="urn:graph:source"` required for source lineage |
| Query-time explanation | Separate graph `urn:graph:retrieval`, e.g. `api/explainability.py:744` `fetch_graphrag_trace`; this proves query lineage, not ingestion completion |

The Python `triples_query` convenience API accepts URI/literal object filters, not RDF-star triple terms. To match a quoted extracted fact, query the source graph by the `tg:contains` predicate and compare the structured object terms; preserve result limits/truncation as incomplete evidence. A graph URI is an identifier for a named graph, not a URL to fetch.

Two provenance caveats matter for this project. First, `chunking/token/chunker.py:154` writes an approximate **token offset** into `charOffset`; line184 advances it by chunk-size minus overlap. It cannot certify an exact character/byte citation span. Retrieve original/child bytes and verify any span independently. Second, initial document provenance in `librarian/service.py:328–383` is sent without `set_graph`, into the default graph, before document processing begins. Finding that metadata does not prove source chunks or extracted facts exist. Explanation content helper `fetch_document_content` also truncates to 10,000 characters by default and returns error strings; use the librarian's full byte-content operation for hash verification.

This source trace does not establish global downstream completion, immutable remote corpus freezing, exact upstream offsets, or any real study approval. Those gates remain explicit.
