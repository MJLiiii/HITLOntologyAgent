## Automation and limits

`.github/workflows/ci.yml` uses immutable action commits, read-only repository permissions and a macOS runner for the actual Seatbelt engine boundary. The local equivalents are exercised here; GitHub Actions has not run because this source repository has not been pushed. The action references were resolved through the GitHub connector. Hosted runner availability is documented by [GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).

The source repository is local. Runtime keys, credentials, application data, downloaded upstream sources, installed dependencies, generated binaries and research-result storage are excluded from source control. Original user document outputs and backups are preserved outside the application commit.

The application is limited to trusted loopback use. Shared identity/deployment, independent evaluator OS identities and mounts, approved real study tasks/data/reviewers and broad OWL benchmark equivalence remain outside this verified release. The authoritative full-plan requirement trace is `docs/requirements-audit.md`; a working local application does not imply every study or integration gate is closed.
